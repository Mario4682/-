# Игра "Познай числото"

Интерактивна игра, създадена с HTML, CSS и JavaScript.  
Целта е потребителят да познае случайно число между 1 и 100, като получава подсказки дали числото е по-високо или по-ниско.

## 🛠️ Използвани технологии

- HTML5
- CSS3
- JavaScript

## ▶️ Как се играе

1. Въведи число между 1 и 100.
2. Натисни бутона "Провери".
3. Ще получиш съобщение дали тайното число е по-голямо, по-малко или вярно.
